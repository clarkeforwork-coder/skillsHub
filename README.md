# SkillsHub

本機執行的私人 Skill 收藏與任務套組管理器。沿用完整 Skill 檔案及來源；支援 Codex 與 Claude Code 的預覽後安裝。

## 啟動

需要 Node.js 22 以上；GitHub 收錄另需 Git。

```sh
npm install
npm start
```

開啟 http://127.0.0.1:4310 。可用 `PORT=4313 npm start` 改變連接埠，或 `SKILLSHUB_DATA=/absolute/path npm start` 指定資料位置。只允許一個伺服器使用同一資料目錄。

## 私人收藏

- 自動載入既有 `.data/catalog.json` 與完整 Skill 檔案，不重新匯入、不用展示資料取代收藏。
- 搜尋名稱、原始描述、自訂用途、適用情境、標籤與筆記；支援常用收藏、最近收錄、標籤及來源篩選。
- 編輯自訂摘要、適用情境、標籤、筆記與常用收藏會寫入本機；不修改原始 `SKILL.md`。
- 右側詳情顯示真實的完整原文、附帶檔案清單、來源及版本。中文摘要由使用者填寫，沒有自動翻譯或語意推薦。
- 支援本機資料夾與 GitHub 公開儲存庫收錄。現階段會匯入指定來源中的所有有效 Skills；尚未提供收錄前逐項挑選，可指定單一 Skill 目錄。
- 相同內容自動略過；同名不同內容以不同識別碼保留。套組成員以識別碼關聯，避免混淆版本。

## 任務套組

- 建立、重新命名、編輯用途、刪除套組。
- 從私人收藏搜尋並加入成員，保留成員順序與各自的使用提示。
- 支援多選加入套組、成員上移／下移、移除及使用提示編輯；每次成功操作立即保存。
- 從套組移除成員或刪除整個套組，不會刪除收藏或安裝檔案。
- 首次使用沒有預設套組；原型中的展示套組不會寫入正式資料。
- 同一套組的過時更新會被拒絕，避免多分頁覆蓋較新的內容；請重新整理後再編輯。

## 工具配置與安裝

- 可從單個 Skill、收藏多選、套組頁或工具配置頁開始安裝。
- 選擇 Codex 或 Claude Code，並指定全域或既有專案資料夾（絕對路徑／`~/`）。
- 全域位置：Codex 使用 `~/.agents/skills`；Claude Code 使用 `~/.claude/skills`。專案位置分別為 `<project>/.agents/skills` 與 `<project>/.claude/skills`。
- 操作順序為選目標 → 讀取實際檔案並預覽 → 明確確認 → 顯示逐項結果。預覽本身不建立資料夾。
- 新項目複製完整收藏與腳本權限；相同內容略過；同名不同內容、不可讀目標、特殊目標或同批選取同名不同版本一律保留原檔，不覆寫、不合併。
- 衝突不阻止同批其他新項目安裝；確認按鈕標示將安裝的數量。每個項目分別回報成功、略過或失敗。
- 伺服器核發十分鐘有效、單次使用的預覽憑證。確認時重新驗證來源／目標狀態，變更或重新啟動後須重新預覽；直接呼叫安裝而沒有有效預覽會被拒絕。
- 安裝完成後保存紀錄並更新工具頁，可查看全域與已記錄的專案配置。不是對所有專案的全面掃描。
- 本版支援來源更新、舊安裝認領、有來源追蹤的套組同步與解除配置；尚未提供保留收藏的單獨解除安裝、強制覆蓋、更新合併或停用；也沒有自動更新、跨裝置同步或語意推薦。

## 資料保存

收藏副本、metadata、任務套組及既有安裝紀錄均在 `.data/`；備份整個資料夾即可。此目錄已加入 `.gitignore`。

升級時若舊目錄沒有套組欄位，先將原始 catalog 備份至 `.data/catalog.before-v2.json`，並在記憶體中初始化空套組清單，下一次儲存才寫回 catalog。原有 Skills、筆記、標籤、識別碼與安裝紀錄均保留。

所有寫入依序處理，先寫暫存檔再原子替換 catalog；保存失敗會回復記憶體狀態。套組保存前驗證成員存在、無重複、順序及提示格式有效。

收錄限制：最多掃描三層；單個 Skill 限 25 MB／2,000 個檔案。不執行內容；略過 `.git`、`node_modules` 與 `.DS_Store`，拒絕附帶符號連結及特殊檔案。GitHub 使用預設分支，網址需為 `https://github.com/owner/repo`，子資料夾另填。

服務僅監聽 `127.0.0.1`，檢查 Host、Origin 與寫入請求標頭；這是單人本機工具，請勿公開代理。

## 驗證

```sh
npm test
```

涵蓋收錄完整性、去重、路徑限制、舊資料遷移、備份、套組持久化與順序、資料驗證、多分頁衝突、刪除不影響收藏、寫入失敗回復等情境。測試使用獨立暫存資料夾。

舊介面原型仍可用 `npm run mockup` 在 http://127.0.0.1:4311 開啟，僅有展示資料、無後端儲存；正式使用請開啟 4310。

### 查看既有專案的 Skills

在「工具配置」選擇 Codex 或 Claude Code，將範圍切換為「指定專案」，輸入專案絕對路徑（或 `~/` 開頭），按「讀取專案配置」。不需要先透過 SkillsHub 安裝；會直接讀取專案的 `.agents/skills` 或 `.claude/skills`，包含尚未收錄的 Skills，並與收藏內容比對。瀏覽器會記住上次成功讀取的專案。

這是該專案 Skills 目錄的清單，不包含全域／上層目錄繼承的 Skills 或工具其他設定檔。讀取不會建立目錄或修改專案；符號連結與無法安全比對的項目會提示，不會執行其內容。

### 多專案清單與資料夾選擇

在「工具配置 → 指定專案」按「選擇資料夾」，用內建的本機資料夾瀏覽器逐層選擇，再按「選擇此資料夾並加入」。可加入多個專案，清單會存於本機 `catalog.json`，之後從「我的專案」選單切換便會重新讀取配置。資料夾選擇器不會上傳檔案；預設從個人資料夾開始，可前往上一層，亦保留直接指定路徑的選項。

安裝視窗共用此專案清單，也可以當場加入新資料夾。「從清單移除」只移除專案紀錄，不刪除專案或其 Skills。相同實際路徑會去重。先前瀏覽器記住的專案會嘗試加入清單；已搬移或不可讀的專案會提示讀取錯誤。

### 套組同步與移除

套組頁的「安裝／同步套組」會以目前成員產生預覽；工具配置中的「已追蹤的套組配置」可再次預覽同步或解除該目標的整套配置。移出成員、刪除私人收藏及解除工具配置是不同操作，不會因編輯套組就立即刪除磁碟檔案。仍有已追蹤配置的套組須先解除配置，才能刪除套組。

新安裝會記錄來源是套組或單獨使用。只有由該套組獨佔、內容與安裝時一致的項目才會列為移除。其他套組共用、曾單獨安裝、內容被修改、符號連結、無法比對或舊版來源不明項目一律保留。首次追蹤既有相同檔案不會取得刪除權。

預覽 token 十分鐘有效、限用一次，確認時重查成員版本、內容及來源關聯。移除前將整個目錄搬至目標 skills 目錄下的隱藏資料夾 .skillshub-recovery/<識別碼>/，並附 restore.json 記錄原位置；結果視窗會顯示備份路徑。若要手動還原，先確認原位置不存在，再將備份的 Skill 資料夾移回 restore.json 的 original 位置；還原不會自動恢復套組來源關聯。此版尚無一鍵還原介面。備份不會自動清除，備份 catalog 時亦應保存這些目標內的備份。

資料庫寫入失敗時會嘗試回復本次新增及搬移；程序中斷留下的備份與 restore.json 可用於恢復。

### 更新既有安裝與兩階段同步

私人收藏及任務套組的「安裝／同步」先列出已安裝的位置：全域、已加入專案與既有紀錄中的專案。選擇現有位置更新，或另選「安裝到新位置」。專案安裝不需要先安裝全域；收藏清單亦顯示專案安裝。每個位置分別預覽並確認。

不再需要另外「認領」。在一般同步預覽，內容完全相同的舊安裝會標為「沿用現有安裝」，確認後記錄同步關聯；套組成員之後可跟隨更新與移除（仍須預覽確認）。有額外檔案或本機修改者不會自動納入。

「檢查來源更新」先從 GitHub／本機抓取快照，確認後只更新私人收藏，保留識別碼、筆記、標籤與套組關聯。接著可直接選擇已安裝位置；與已保存舊版指紋完整一致的安裝，可在預覽中更新並記錄同步關聯，無需額外步驟。缺乏可信舊版指紋或手動修改的內容仍列為衝突保留。

來源檢查為手動單個 Skill 操作，不會定時或一次更新所有工具與專案。來源預覽有效十分鐘、套用當次快照，服務重新啟動會使預覽失效。收藏備份在 .data/recovery/，工具備份在各目標 .skillshub-recovery/；尚無一鍵還原或強制覆蓋。

### 從私人收藏移除並解除安裝

在右側詳情「⋯ → 從私人收藏移除」先預覽。確認後會備份收藏與筆記、移出套組成員，並一併解除預覽標示的安裝。檢查包含兩個工具的全域、已加入的專案，以及既有安裝紀錄；未加入且無紀錄的專案無法自動發現。

與收藏完整一致、或已納管且仍符合原安裝指紋的檔案可備份移除。手動修改、無法比對或其他收藏版本使用中的項目保留並列出原因。若本機來源就是安裝目錄，也會備份移除；獨立來源資料夾及遠端 GitHub 不受影響。

收藏備份在 .data/recovery/；安裝備份在各目標 .skillshub-recovery/，結果視窗顯示位置。確認時重新檢查，變更過的預覽不可使用。儲存或解除安裝失敗時會嘗試回復本次所有搬移；目前尚無一鍵還原介面。
