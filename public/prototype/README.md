# SkillsHub v2 UI mockup

本次要確認：私人收藏 → 任務套組 → 工具配置，這三個畫面的資訊與操作是否容易理解。

啟動：在專案根目錄執行 `npm run mockup`。

- 私人收藏：http://127.0.0.1:4311/?screen=library
- 任務套組：http://127.0.0.1:4311/?screen=packs
- 工具配置：http://127.0.0.1:4311/?screen=tools

這是同一設計方向的三個工作區，並非三種視覺風格。使用獨立靜態預覽服務，避免接入原有後端。展示資料、筆記、配置與活動紀錄皆為示意；編輯僅存在記憶體，重新整理後重置。原有 4310 應用程式、收藏資料與安裝目錄不變。

可試用：搜尋與篩選、詳情分頁、收藏、編輯筆記、模擬收錄、建立／編輯套組、加入／移除／排列成員、選擇工具與專案、套用前預覽、模擬停用與重新配置、查看示例差異。

此版沒有 API、持久化、真實檔案讀取、下載或安裝。尚未定案，請勿直接作為正式功能發佈。
